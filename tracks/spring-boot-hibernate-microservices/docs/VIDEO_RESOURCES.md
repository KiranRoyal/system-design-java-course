# Additional full length lectures

The course includes original downloadable videos for every module. These external lectures offer longer demonstrations by their original creators. They are linked, not downloaded or republished. Links were checked through the creator’s site or video metadata on 6 November 2026; external playback and audio quality were not exhaustively audited. Captions and availability are controlled by the publisher.

- [Getting Started with Java — Dan Vega](https://www.youtube.com/playlist?list=PLZV0a2jwt22sSlfykcq8PDK0K5o-ZIpit): environment and Java foundations, alongside modules 01–04.
- [Spring Boot crash course — Dan Vega](https://www.youtube.com/watch?v=UgX5lgv4uVM): a nearly four-hour introduction, alongside modules 05–10. [Creator’s explanation](https://www.danvega.dev/blog/spring-boot-crash-course).
- [Building web applications in Java with Spring Boot 3](https://www.youtube.com/watch?v=31KTdfRH6nY): longer application walkthrough linked from [Dan Vega’s course catalog](https://www.danvega.dev/courses/).
- [Hibernate 7 reference guide](https://docs.hibernate.org/orm/7.2/introduction/html_single/): use with the original Hibernate lectures 12–15 for precise mapping and fetching details.

The external Spring Boot videos use Boot 3. The repository uses Boot 4.0.9, its modular starters, Jakarta APIs, and managed Hibernate 7.2.25.Final. Keep the concepts, then consult version-matched documentation for imports and dependency changes.
