# Additional full length lectures

The course includes original downloadable videos for every module. These external lectures offer longer demonstrations by their original creators. They are linked, not downloaded or republished. Links were checked through the creator’s site or video metadata on 6 November 2026; external playback and audio quality were not exhaustively audited. Captions and availability are controlled by the publisher.

- [AI for Java Developers — Dan Vega](https://www.youtube.com/watch?v=FzLABAppJfM): the creator describes a 5.5-hour Spring AI masterclass. Use alongside modules 03–13. [Creator’s course catalog](https://www.danvega.dev/courses/).
- [How to Build Agents with Spring AI — Microsoft for Java Developers](https://www.youtube.com/watch?v=d7m6nJxfi0g): Adib Saikali’s Java agent patterns session. Use with modules 07–09 and 18.
- [Microsoft Learn Java and Spring AI training](https://learn.microsoft.com/en-us/training/modules/build-enterprise-ai-agents-with-java-spring/): guided enterprise integration exercises. Cloud resources may incur charges; the included local labs do not require them.

Some external demonstrations use Spring AI 1.x. Follow this repository’s pinned 2.0.2 dependencies and current documentation when adapting code; do not copy old imports and configuration blindly.
